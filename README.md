# WT Live Skin Installer

Расширение для Chrome, Opera и Vivaldi (Manifest V3). Добавляет кнопку «Установить скин» рядом со скачиванием публикации на [WT Live](https://live.warthunder.com/feed/camouflages/). Архив распаковывается в `War Thunder/UserSkins`. Для игры в папке `AppData` на Windows нужен локальный помощник (инструкция ниже).

## Установка расширения

1. Откройте `chrome://extensions` в Chrome, `opera://extensions` в Opera или `vivaldi://extensions` в Vivaldi.
2. Включите режим разработчика и выберите **Загрузить распакованное расширение**.
3. Укажите папку `extension` из этого проекта.
4. Откройте публикацию камуфляжа на WT Live и нажмите **Установить скин**.
5. В новой вкладке нажмите **Выбрать UserSkins**, укажите папку `UserSkins` внутри установленной игры, затем нажмите **Установить**. При следующих установках папка запоминается; браузер может повторно запросить право записи. Если браузер пишет «can't open this folder because it contains system files», используйте помощник ниже.
6. В игре обновите список пользовательских камуфляжей.

После обновления файлов проекта нажмите **Обновить** на карточке расширения на странице расширений и перезагрузите вкладку WT Live.

Если папки `UserSkins` ещё нет, создайте пример камуфляжа в игре или создайте папку вручную. Каждый файл `.blk` из архива устанавливается как отдельный скин. Существующие папки не перезаписываются.

## AppData on Windows

Chromium запрещает браузерный доступ к `AppData`, включая `C:\Users\<имя>\AppData\Local\WarThunder\UserSkins`. Папка `lang` для скинов не подходит. Локальный помощник устанавливается один раз и работает с Chrome и Vivaldi без прав администратора.

1. [Скачайте WT-Live-Setup.exe](https://github.com/piksel-man231/wt-live-skin-installer/releases/latest/download/WT-Live-Setup.exe) и запустите его двойным кликом. Он сам найдёт установленное расширение, обновит его до версии 0.3.1 и настроит папку `%LOCALAPPDATA%\WarThunder\UserSkins`. В конце появится окно с результатом. Права администратора не нужны.
2. Полностью закройте и снова откройте браузер, затем перезагрузите страницу WT Live. Теперь кнопка **Установить скин** сразу устанавливает скин и показывает результат прямо на кнопке. Страница расширения открывается только до первой настройки или когда браузер снова требует доступ к выбранной папке.

Если игра расположена не в `%LOCALAPPDATA%\WarThunder`, в проекте остаётся расширенная настройка через `native/install.ps1` с параметрами `-ExtensionId` и `-UserSkins`. Помощник скачивает только камуфляж с WT Live по номеру публикации и сохраняет разрешённые файлы (`.blk`, текстуры, текст) в новые папки внутри указанной `UserSkins`.

## Проверка

`node --test tests/*.test.cjs`

`cd native && go test ./...`

Архивы ограничены 250 МБ при скачивании, 1 ГБ распакованных данных и 500 файлов. Устанавливаются только изображения, текстовые файлы и `.blk`. Код распаковки [fflate 0.8.2](https://github.com/101arrowz/fflate) включён локально в `extension/vendor/fflate.js` (MIT).
