# WT Live Skin Installer

Расширение для Chrome, Opera и Vivaldi (Manifest V3). Добавляет кнопку «Установить скин» рядом со скачиванием публикации на [WT Live](https://live.warthunder.com/feed/camouflages/). Архив распаковывается прямо в выбранную пользователем папку `War Thunder/UserSkins`. Отдельный сервер или приложение не нужны.

## Установка расширения

1. Откройте `chrome://extensions` в Chrome, `opera://extensions` в Opera или `vivaldi://extensions` в Vivaldi.
2. Включите режим разработчика и выберите **Загрузить распакованное расширение**.
3. Укажите папку `extension` из этого проекта.
4. Откройте публикацию камуфляжа на WT Live и нажмите **Установить скин**.
5. В новой вкладке нажмите **Выбрать UserSkins**, укажите папку `UserSkins` внутри установленной игры, затем нажмите **Установить**. При следующих установках папка запоминается; браузер может повторно запросить право записи.
6. В игре обновите список пользовательских камуфляжей.

После обновления файлов проекта нажмите **Обновить** на карточке расширения на странице расширений и перезагрузите вкладку WT Live.

Если папки `UserSkins` ещё нет, создайте пример камуфляжа в игре или создайте папку вручную. Каждый файл `.blk` из архива устанавливается как отдельный скин. Существующие папки не перезаписываются.

## Проверка

`node --test tests/*.test.cjs`

Архивы ограничены 250 МБ при скачивании, 1 ГБ распакованных данных и 500 файлов. Устанавливаются только изображения, текстовые файлы и `.blk`. Код распаковки [fflate 0.8.2](https://github.com/101arrowz/fflate) включён локально в `extension/vendor/fflate.js` (MIT).
